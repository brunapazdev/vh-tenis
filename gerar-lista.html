Gerar lista de fotos

Lê a sua pasta fotos e monta o bloco que você cola no index.html. Nada é enviado para a internet.

  1. Clique em “Escolher pasta fotos” e selecione a pasta fotos inteira (a que tem masculino, feminino…).
  2. Copie o resultado.
  3. No index.html, apague o bloco const FOTOS = { ... }; e cole este no lugar.
  4. Suba o index.html e a pasta fotos para o GitHub.
